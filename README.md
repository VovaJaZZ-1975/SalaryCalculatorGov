# Калькулятор зарплаты государственного гражданского служащего

## Описание
Полноценное Android-приложение для расчета денежного содержания госслужащих (на основе модели 2026 года), ведения финансовой истории, постановки целей и планирования накоплений. 
Приложение работает полностью оффлайн и гарантирует приватность финансовых данных.

## Возможности
*   **Калькулятор ЗП**: Расчет с учетом окладов, выслуги, надбавок (гостайна, особые условия, ЕДП) и премий.
*   **История**: Сохранение ежемесячных начислений.
*   **Аналитика**: Графики дохода и структуры выплат.
*   **Финансовые цели**: Постановка целей с умным прогнозом даты достижения.
*   **Накопления**: Поддержка фиксированных сумм, процента от ЗП/премий и разных периодов накоплений.
*   **What-If**: Симуляция сценариев изменения дохода без влияния на основную историю.
*   **Адаптивный UI**: Поддержка смартфонов и планшетов (портретный и ландшафтный режимы) через Material 3 и WindowSizeClass.

## Архитектура
Проект построен по принципам Clean Architecture:
*   **UI**: Jetpack Compose, MVVM, StateFlow, Navigation Compose.
*   **Domain (Calculation Engine)**: Изолированный Kotlin-модуль, использующий `BigDecimal` для исключения ошибок округления чисел с плавающей точкой.
*   **Data**: Room Database для локального хранения, DataStore для настроек.

## Сборка проекта
Для локальной сборки потребуется Android Studio и установленный Android SDK (minSdk 24, targetSdk 34).
```bash
git clone <ваш-репозиторий>
cd SalaryCalculatorGov
./gradlew test
./gradlew assembleDebug
```
Собранный APK будет находиться в `app/build/outputs/apk/debug/app-debug.apk`.
